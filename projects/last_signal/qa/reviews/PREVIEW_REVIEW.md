# Preview review — 38 pinned stills (M4 vision review)

**Verdict: FAIL** — 27 of 38 stills do not communicate their shot. Most failures come from a few
builder gaps: no phone UI, props not held or not built, poses picked per scene rather than per shot,
passenger-side body not wild. Four spec problems also need the cinematographer, world-designer and
look-director. G6 is already approved as a blockout. This verdict is advice for the next preview pass and does not reopen G6.

**Counts:** FAIL 27 · WARN 10 · PASS 1. Problem classes (one shot can have several): BUILDER on 37 shots,
SPEC on 6 shots, plus one look-director dependency across all inserts (4 distinct spec issues).

Method: I opened each still (960 x 540) with the Read tool and compared it with its
`08_shots/<id>.shot.yaml` (creative_intent, composition, characters, lighting, color, animation.props)
and `09_resolved/<id>.json`. I traced causes in `blender/fm_blender/{preview,sets,characters}.py` and the
`10_blender/logs`. Static and proxy figures were ignored as instructed. I judged only whether each frame reads.

## What the human should look at first
1. **The phone never shows its UI (14 FAIL shots).** Every insert renders the same placeholder: a cream
   screen with a navy bar and an amber bar (`preview.py:260-269`). There is no map pin, photo, percentage,
   bolt, invitation, heart or tick, so the battery race (`intent.race_against_battery`) and the climax
   `SC04_SH080` (`intent.earned_last_signal`) cannot be read. The amber bar shows before anything is
   charging, which uses up `look.color.accent_power_amber`. `09_resolved` carries only `ui.*` ids with
   no content.
2. **The crank, the object of hope, is missing or unreadable.** It is not built in `SC04_SH040`, it is
   below frame in `SC04_SH050` and `SC04_SH090`, and it is cropped in `SC01_SH110`. Where it does appear,
   it is painted accent amber instead of `look.color.props` crank_body #D6C592 (`preview.py:241-244`).
3. **The car reads as the wrong colour and blocks the camera.** The body uses palette index 6 =
   `car_glass_tint` #9FB0C4 instead of `car_paint` #E8D8A8 (`sets.py:104`), so SC01 reads cool
   blue-grey against `look.color.scene.sc01` (dominant #F6D7A7). The passenger-side body is never made
   wild, so it hides Ren in `SC01_SH060/100/130`. The roof slab runs forward over the windscreen, so it
   hides his head in `SC01_SH150`.
